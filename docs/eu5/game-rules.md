# Game Rules & Setup

Before starting a campaign, Elf Destiny adds a couple of its own **game rules** to
the new-game screen. They cannot be changed once a game begins, so it is worth
deciding on them up front.

## Rarity of Genetic Traits

Controls how often [genetic traits](pops-cultures.md) — beauty, physique, intellect
and the like — appear. The setting affects how frequently traits spawn on newly
generated characters, and the odds of a newborn gaining an *uninherited* trait. It
does **not** change the normal rules for how traits are passed from parent to child.

| Setting | Effect |
|---|---|
| **Normal Rarity** *(default)* | Genetic traits spawn at the standard rate. |
| **More Common** | Genetic traits spawn more frequently. |
| **More Rare** | Genetic traits spawn less frequently. |

A higher rarity makes the [bloodline](../lore/bloodlines-and-dynasties.md) game of
breeding for gifted heirs faster and more forgiving; a lower rarity makes prized
traits genuinely scarce.

## Character Editor Availability

Elf Destiny includes a **Character Editor** — a character interaction that lets you
directly change a character's genetic and racial traits. This rule decides when it
is available.

| Setting | Effect |
|---|---|
| **Enabled only in Debug mode** *(default)* | The Character Editor appears only when the game is run in debug mode. |
| **Enabled outside of Debug mode** | The Character Editor is available in normal play. |

The editor is a powerful tool — it can hand a character any trait or [Ascension](../lore/elven-ascension.md)
tier outright. Leave it on the default if you want a traits-and-bloodlines
playthrough to feel earned; switch it on if you would rather build characters
freely.
